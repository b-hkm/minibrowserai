My Browser

A tiny HTML browser in C++/SDL. Click links to navigate, use Alt+Left / Alt+Right for back/forward, F5 to reload, Ctrl+F to find in page, Ctrl+= / Ctrl+- to zoom, Ctrl+L to focus the address bar, Tab to cycle focus between inputs/links/buttons.

New in 2.0

  • HTTP/HTTPS: type any URL in the address bar (Ctrl+L), e.g. example.com — pages, stylesheets, scripts and images are fetched with libcurl (gzip + redirects + TLS included).
  • Real JavaScript (Duktape): closures, functions with arguments and return values, loops, arrays, JSON — see below.
  • Synchronous fetch() / XMLHttpRequest for remote pages.
  • CSS upgrades: rgba() colors, #abc hex shorthand, font-size in em/%/pt, line-height, text-transform, background-image url().
  • Bookmarks (Ctrl+D, bar with Ctrl+B), view source (Ctrl+U), save page (Ctrl+S), fullscreen (F11), drag & drop an .html file onto the window to open it.
  • Form GET submits build real query strings; #fragment links scroll to anchors; back/forward restore your scroll position.

Features demonstrated on this page

  • External CSS via <link rel="stylesheet">
  • Inline CSS via <style>
  • Compound selectors like nav a and .card p
  • CSS :hover — hover over the nav links or the card below
  • CSS display: none, text-align: center/right
  • CSS width / height — see the fixed box below
  • Unordered lists with bullets, ordered lists with numbers
  • Tables with headers, <hr>, <blockquote>
  • <dl> / <dt> / <dd> definition lists
  • Long-word breaking
  • Form inputs — click the text fields below, type, Tab to cycle
  • JS setTimeout — see "Async demo" below
  • JS addEventListener — see "Event listener demo" below
  • Find in page with Ctrl+F (try searching for "browser")
  • Page zoom with Ctrl+= / Ctrl+- / Ctrl+0
  • Editable address bar — click it or press Ctrl+L
